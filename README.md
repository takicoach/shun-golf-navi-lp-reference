## 見る・使う

1. **Code → Download ZIP** でダウンロードし、展開します。
2. **`index.html` をChrome等で開く**と、ネット接続なしで参考LPを見られます。
3. スマホ／PCの元ページ全景は [`screenshots/`](screenshots/)、文章は [`copy.txt`](copy.txt) を参照してください。

GitHub上のHTMLファイル表示はソースコード表示です。サイトとしての公開（GitHub Pages）は設定していません。

| ファイル | 内容 |
|---|---|
| `index.html` | 公開用の静的プレビュー。申込リンク・フォーム・動的処理は無効 |
| `assets/` | 画像66点、フォント57点、フォント用CSS3点 |
| `screenshots/desktop-full.png` / `mobile-full.png` | 元LPのPC／スマホ幅の全ページ画像 |
| `copy.txt` | 表示されていた文章の全文 |
| `reference/utage-custom-block.html.txt` | UTAGEに入っていたHTMLブロックの参考コード。誤実行防止のためテキスト形式 |

| `manifest.json` | 出所・取得時刻・公開用エクスポート時のファイルハッシュ |

UTAGEの元レスポンス全体・ページ設定JSON・MHTML・訪問者の計測パラメーター・タグマネージャー・UTAGE等の配信JavaScript/CSS・ローカル作業パスは含めていません。未加工原本は別途ローカルに保管しています。

元の画像・文章・装飾コードを参考にするための資料です。申込先・料金・無料条件・期限・実績・利用者の声を、別サービスへそのまま流用しないでください。テキスト形式のコード原本には当時の公開リンクや日時が残っています。

- 取得日時点の内容です。カウントダウンは固定表示、スクロールに連動する演出は静止状態です。
